# Épica 11: Calidad y pruebas (HU-93 a HU-98)
MVP rápido, accesible y con la lógica crítica probada.

## HU-93 · Pruebas de ingesta
Como desarrollador, quiero pruebas unitarias de la lógica de ingesta, para cambiarla sin miedo a romperla.
- Pruebas de normalización, descarte, deduplicación, restricciones y confianza
Req.: RF-32

## HU-94 · Pruebas de la API
Como desarrollador, quiero pruebas de la API, para garantizar los filtros y las protecciones.
- Combinaciones Y/O, paginación, frágiles sin coordenadas exactas y ocultos excluidos
Req.: RF-26, RF-27

## HU-95 · Página 404
Como visitante, quiero una página 404 útil, para volver al sitio si llego a una ruta inexistente.
- Mensaje claro y enlace a inicio y explorar
Req.: RNF-01

## HU-96 · Imágenes optimizadas
Como visitante, quiero que las imágenes carguen rápido, para no gastar datos móviles.
- Imágenes optimizadas y con carga diferida
- Tamaño adecuado por pantalla
Req.: RNF-03

## HU-97 · Accesibilidad
Como visitante, quiero que el sitio sea accesible, para usarlo con teclado o lector de pantalla.
- Contraste AA
- Navegación completa con teclado
- Texto alternativo en imágenes
- Etiquetas en formularios
Req.: RNF-04

## HU-98 · Rendimiento móvil
Como visitante, quiero que la ficha cargue rápido en el celular, para consultarla en el camino.
- Menos de 2,5 s en 4G
- Lighthouse móvil con rendimiento ≥ 90
Req.: RNF-03
